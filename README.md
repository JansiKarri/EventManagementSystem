# Event Management System

## Overview
The Event Management System is a Spring Boot application that allows users to create, manage, and register for events. It supports features like event creation, user registration, and the ability to manage event registrations.

This project utilizes Spring Boot for the backend, providing REST APIs for interacting with the application, and uses MySQL for the database.

## Features
- **Event Management**: Create and manage events.
- **User Registration**: Register users and assign roles.
- **Event Registration**: Users can register for events.
- **CRUD Operations**: Full support for Create, Read, Update, and Delete operations for events and user registrations.

## Tech Stack
- **Backend**: Java,Rest API
- **Database**: MySQL
- **Dependency Management**: Maven

## Getting Started

### Prerequisites
To run this project locally, you need:
- JDK 11 or later
- MySQL Database
- Maven
- Postman (for API testing)
